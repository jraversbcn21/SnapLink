```
SnapLink copies the title and URL of the current page to your clipboard as a formatted hyperlink.

Paste it into Word, Excel, Google Docs or Notion and you get a clickable link with the page title as its text, not a raw URL.

It works on any website. On issue trackers such as Jira or GitHub it finds the ticket title automatically. On other sites it falls back to the page's Open Graph title, then the main heading, then the page title. You can edit the title before copying.

No login, no API calls, no data collection. Everything runs locally in your browser.

How to use:
- Click the extension icon, check or edit the title, then click Copy as Link.
- Or press Ctrl+Shift+L on any page to copy instantly, with a short confirmation and no popup.

Options:
- Copy as Markdown: [title](url).
- Include or remove the ticket ID from the title.
- Tracking parameters are removed from the copied URL automatically.

Paste behavior:
- Rich-text editors: a formatted hyperlink.
- Excel: select a cell (not in edit mode) and press Ctrl+V.
- Plain text editors: "Title - URL".
- Markdown mode: [Title](URL).
```
